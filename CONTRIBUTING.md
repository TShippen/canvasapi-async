# Contributing

This project is not accepting contributions at this time.

`canvasapi-async` is a personal fork of
[CanvasAPI](https://github.com/ucfopen/canvasapi) in early development.
Issues and pull requests are turned off on this repository.

If you found a bug in the upstream library, report it to
[ucfopen/canvasapi](https://github.com/ucfopen/canvasapi/issues).

To report a security problem privately, use "Report a vulnerability" on this
repository's Security tab.

You are welcome to fork this repository and use it under the terms of the
[MIT License](LICENSE).
